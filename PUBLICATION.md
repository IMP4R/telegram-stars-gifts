# TelegramStarsGifts

Исходный снимок для ознакомления. Секреты, аккаунты, cookies, сессии, рабочие JSON и базы не включены. Оригиналы не изменены.
FunPayAPI устанавливается отдельно; его vendor-копия не включена. Нужны собственные ключи и настройки. Runtime, заказы и реальные оплаты не запускались. Новая лицензия этому снимку не назначается.
Последняя выбранная пользователем версия: StarGiftCardinalPlugim.py 1.2.0 (Kurigram), 2795 строк до очистки, из code_serverC_deleted.tar.gz / root/FunPayCardinal/plugins/, mtime 2026-05-22. Поле CREDITS очищено в копии. Требует FunPay Cardinal; при отсутствии Kurigram исходный плагин автоматически запускает pip install — учтите это перед запуском.
