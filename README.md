# TelegramStarsGifts

Плагин FunPay Cardinal для Telegram Stars и подарков с интеграцией Kurigram.

## Состав

- `PUBLICATION.md`
- `StarGiftCardinalPlugim.py`
- `requirements.txt`

## Подготовка и запуск

Манифесты зависимостей в этой копии:
- [requirements.txt](requirements.txt)

Установите зависимости в отдельное виртуальное окружение: `python -m pip install -r requirements.txt`.

Не импортируйте и не запускайте незнакомые модули автоматически: возможны сетевые запросы, платежные операции и другие внешние эффекты. Отсутствующие данные, сервисы и конфигурацию нужно подготовить самостоятельно.
